Repository

A repository is where all project information is stored...

git init

or

git init <repository name>
Commit

A commit is a snapshot of the changes in the repository...

git add *

Then save these changes to the repository:

git commit -m "First commit"
Branch

A branch is an independent line of development...

git branch <branch name>

To switch to a different branch:

git checkout <branch name>
Merge

A merge is the combination of two branches...

git checkout main

Then perform the merge:

git merge new-branch
